# Интерактивные учебные пособия по информатике

Коллекция интерактивных HTML-пособий для уроков информатики.

## Пособия

| Пособие | Ссылка |
| --- | --- |
| Измерение информационного объёма текста и графического изображения | [Открыть](https://kovalenko130892.github.io/inf-helpers/) |

## Как пользоваться

Откройте ссылку в браузере — установка не требуется, страница работает целиком на клиенте.

- **Теория** — формулы `V = K · i` и `V = W · H · i`, единицы измерения, типичные ловушки.
- **Пошаговый калькулятор** — проверка каждого шага решения (биты на символ, объём, перевод в байты и КБ).
- **Тренажёр** — автоматически генерируемые задания с вариантами ответов и разбором решения.
- **Шпаргалка** — компактная сводка формул, степеней двойки и глубин цвета.

## Добавление нового пособия

Положите файл `название.html` в корень репозитория и добавьте строку в таблицу выше. GitHub Pages раздаёт статику из ветки `main`.
